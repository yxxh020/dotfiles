# Antigravity CLI 계정 스위처 (`as`) 멀티 계정 설정 및 가이드

Google Antigravity CLI(`agy`) 사용 시 모델 쿼터(Quota/Rate Limit) 제한에 도달했을 때, 개인(`personal`) 계정과 회사(`orca`) 계정 간을 단 1초 만에 전환할 수 있는 도구입니다.

macOS 시스템 Keychain 및 파일 토큰을 원자적으로 동기화 전환하여 세션 끊김 없는 계정 스위칭을 제공합니다.

---

## 1. 계정별 최초 1회 등록 방법 (PC당 1회)

인증 토큰은 보안상 Git에 커밋되지 않으므로, 새 기기에서는 각 구글 계정으로 최초 1회 브라우저 로그인을 거쳐야 합니다.

### [1단계] personal 계정 등록
1. 로그인 준비 모드 실행 (기존 토큰 분리):
   ```bash
   as login p
   ```
2. `agy` 실행 후 자동으로 열리는 웹 브라우저에서 **개인 구글 계정**으로 로그인 및 권한 승인:
   ```bash
   agy
   ```
3. 로그인이 완료되면 `Ctrl + D`로 `agy`를 종료합니다.
4. 방금 로그인된 토큰을 저장:
   ```bash
   as save p
   ```

### [2단계] orca 계정 등록
1. 로그인 준비 모드 실행:
   ```bash
   as login o
   ```
2. `agy` 실행 후 웹 브라우저에서 **회사 구글 계정**으로 로그인 및 권한 승인:
   ```bash
   agy
   ```
3. 로그인이 완료되면 `Ctrl + D`로 종료합니다.
4. 방금 로그인된 토큰을 저장:
   ```bash
   as save o
   ```

---

## 2. 일상 사용 방법

초기 1회 등록이 완료된 후에는 브라우저 인증 없이 터미널에서 즉시 전환됩니다.

### 2-1. 현재 활성 계정 확인
```bash
as
# 또는
as status
```
**출력 예시:**
```text
=== Google Antigravity (agy) 계정 상태 ===
  ● personal (활성)
  ○ orca
```

### 2-2. 계정 전환 (쿼터 스위칭)
- **orca 계정으로 전환**:
  ```bash
  as o
  # (또는 as orca)
  ```
- **personal 계정으로 전환**:
  ```bash
  as p
  # (또는 as personal)
  ```

---

## 3. 핵심 팁
- **실행 중인 agy 세션**: 이미 켜져 있는 `agy` 세션 내부는 이전 토큰이 메모리에 상주하므로, 계정 전환 후에는 기존 `agy` 세션을 종료(`Ctrl + D`)하고 새로 실행해야 바뀐 계정이 적용됩니다.
- **빠른 실행 테스트**: `agfm "hello"` 명령어로 현재 활성 계정의 정상 작동을 즉시 확인할 수 있습니다.
