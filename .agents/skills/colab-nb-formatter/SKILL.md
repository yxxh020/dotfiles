# `colab-nb-formatter` 스킬 지침서 (Colab/Jupyter 셀 분리 패턴)

이 스킬은 Jupyter Notebook(.ipynb) 파일을 디자인하거나 기존 코드를 리팩토링할 때 사용하는 지침이다.

## 핵심 목적

코드를 하나의 거대한 셀에 몰아넣지 않고, **[마크다운(설명) 셀] → [코드 셀] → [마크다운(설명) 셀] → [코드 셀]** 형태로 잘게 쪼개어 번갈아 배치한다.

## 작성 규칙 및 패턴

### 1. 연속된 마크다운 셀 생성 금지 (Merge Consecutive Markdown Cells)

여러 단계의 설명이 이어지더라도 **마크다운 셀을 여러 개로 분리하지 않는다.**
코드 셀이 나오기 전까지의 모든 텍스트 설명은 **단 하나의 마크다운 셀** 안에 모두 합쳐서 작성한다. 오직 "마크다운"과 "코드"만 별도 셀로 구별한다.

### 2. 논리적 단계별 셀 분리 (Alternating)

코드는 독립적인 기능을 수행하는 단위로 셀을 쪼개고, 그 앞에는 1개의 마크다운 셀만 위치시킨다.

* **[마크다운 1]** 실습 목표 + 준비사항 + 첫 번째 로직 설명
* **[코드 1]** 모듈 불러오기 (`import`)
* **[마크다운 2]** 다음 로직 설명
* **[코드 2]** 데이터 로드 및 변수 초기화
* **[마크다운 3]** 핵심 로직 설명
* **[코드 3]** 핵심 로직 실행

### 3. 마크다운(설명) 셀 작성법

* **눈높이 비유**: 대상 독자 수준에 맞는 직관적인 비유를 사용한다.
  * 예: `import` → "도구함 가져오기", `list` → "빈 바구니"
* **조작법 안내**: 코드를 어떻게 실행하는지 행동 유도(Call to Action) 문장을 포함한다.
  * 예: "아래 코드 셀을 클릭하고 `Shift + Enter`를 눌러 실행하세요."
* **실행 버튼 명칭 통일**: Colab의 코드 실행 버튼은 "**실행(▶️)**" 버튼으로 명칭을 통일한다.

### 4. 코드 셀 주석 작성법

코드 셀 안에서도 각 줄이나 중요한 블록마다 주석(`#`)을 달아 직관적으로 이해할 수 있게 돕는다.

### 5. JSON 포맷팅 호환성 유지

AI가 스크립트나 터미널을 통해 `.ipynb` 파일을 직접 수정할 경우, Notebook 내부 구조가 망가질 수 있다.

* 파일 수정 시, 셀(cell) 안의 `source` 항목이 단일 거대 문자열(String)이 아니라 **줄바꿈(`\n`)이 포함된 문자열 배열(List of strings)** 형태로 저장되도록 포맷을 유지한다.
* 수정 후 `python3 -m json.tool <파일명> > /dev/null` (또는 `jq . <파일명> > /dev/null`)로 JSON 유효성을 검증한다.

## 훌륭한 패턴 예시

**[마크다운 셀 1]** (여러 설명이 합쳐진 형태)
```markdown
# 실습 목표
오늘은 데이터 분석 파이프라인을 만듭니다.

## Step 1: 파일 준비
왼쪽 폴더에 데이터 파일을 업로드하세요.

## Step 2: 모듈 가져오기
파이썬에는 모든 기능이 처음부터 다 들어있지 않습니다.
* `import pandas`: 데이터를 표 형태로 다룰 수 있는 '스프레드시트 도구함'을 가져옵니다.

아래 코드 셀을 클릭하고 `Shift + Enter`를 눌러 도구함들을 먼저 준비해 주세요.
```

**[코드 셀 1]**
```python
import pandas as pd   # 데이터 분석 도구함 가져오기
import matplotlib.pyplot as plt  # 그래프 그리기 도구함 가져오기
```
