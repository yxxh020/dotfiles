# 로컬 문서 자동 분류기 스킬 (Local Classifier Skill)

이 스킬은 사용자가 "다운로드 폴더의 파일들을 정리해 줘" 또는 "이 문서들을 카테고리별로 자동 분류해 줘"라고 요청할 때 발동됩니다.

## 동작 원리 및 지침
당신(AI 에이전트)은 다음 절차에 따라 작업을 수행합니다:

1. **대상 파일 수집**: 터미널 도구를 사용하여 사용자가 지정한 디렉터리의 파일 목록(`ls`가 아닌 시스템의 도구 활용)을 가져옵니다.
2. **카테고리 추론**: 각 파일을 `view_file` 또는 로컬 텍스트/PDF 파싱 파이프라인(예: `pdftotext` 등)을 통해 내용을 스캔한다. 보통 파일의 앞 500자만 읽어도 분류가 가능한다.
3. **분류 기준**: 내용을 기반으로 다음 4가지 기본 카테고리 중 하나를 선택한다.
   - `영수증` (결제, 금액, 승인번호 등이 포함된 내용)
   - `계약서` (서명, 약관, "갑과 을" 등이 포함된 내용)
   - `개발문서` (소스코드 조각, API 명세, 아키텍처 다이어그램 등)
   - `개인메모` (그 외의 일반적인 텍스트나 일기 등)
4. **폴더 생성 및 이동**:
   - 판단된 카테고리에 맞게 `mkdir -p /대상디렉터리/영수증/` 등의 명령을 실행하여 폴더를 만듭니다.
   - `mv /대상디렉터리/원본파일 /대상디렉터리/카테고리/` 명령을 실행하여 파일을 이동시킵니다.
5. **최종 보고**: 모든 파일의 정리가 끝나면 "N개의 파일을 영수증 폴더로, M개의 파일을 개발문서 폴더로 분류 완료했습니다"라고 최종 결과를 사용자에게 보고한다.

## 주의 사항
- 이동(`mv`) 명령어 실행 전, 원본 파일의 이름에 공백이나 특수문자가 포함되어 있을 경우 Bash 쉘 에러가 나지 않도록 반드시 파일 경로를 따옴표(`"`)로 감싸야 한다.
- 내용을 파악하기 어려운 이미지 파일의 경우, 사전에 구축된 `local-ocr` 스킬 지침을 병행하여 텍스트를 추출할 수 있다.
