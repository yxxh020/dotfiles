# ntfy-alert

AI 에이전트가 긴 작업을 완료했거나 사용자에게 푸시 알림으로 보고해야 할 상황일 때, `ntfy.sh`를 활용하여 메시지를 발송할 수 있는 스킬이다.

## 지침 (Instructions)

1. **가이드 문서 확인**:
   알림을 보내기 전, 반드시 `references/ntfy-guide.md` 파일을 읽어보고 `ntfy.sh` 사용 방법과 알림을 보낼 토픽(Topic) 주소를 확인해라. (이 파일은 옵시디언 볼트의 원본 문서를 가리키는 심볼릭 링크이다.)

2. **알림 발송 실행**:
   - `run_command` 툴을 사용해 가이드 문서에 안내된 `curl` 명령어를 실행한다.
   - 상황에 맞는 우선순위(Priority)와 이모지 태그(Tags)를 지정해라 (예: 성공 시 `tada`, 오류 발생 시 `rotating_light` 또는 `warning`).
   - 매우 오래 걸린 작업이나 사용자가 명시적으로 알림을 요구한 작업의 완료 시에는 별도 권한 요청 없이 즉시 알림을 보내도 됩니다.
