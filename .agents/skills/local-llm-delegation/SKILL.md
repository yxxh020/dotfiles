# 로컬 모델 위임 스킬 (Local LLM Delegation Skill)

이 스킬은 사용자가 "로컬 모델에게 물어봐 줘" 또는 "로컬 모델에 넘겨서 요약해 줘"라고 요청할 때 발동됩니다. 보안상 민감한 문서를 처리하거나, 오프라인 상태에서 AI의 추가 의견을 구하고 싶을 때 사용됩니다.

## 동작 원리 및 지침
사용자의 지시를 받으면, 당신(현재 AI 에이전트)은 다음 단계를 수행합니다:

1. 사용자가 전달한 내용(코드, 문서, 질문 등)을 프롬프트 문자열로 안전하게 이스케이프(escape) 처리한다.
2. 터미널 도구(명령어 실행 도구)를 사용하여 다음 명령어를 쉘에서 실행한다.
   ```bash
   ollama run qwen2.5-coder:7b "{정제된 프롬프트}"
   ```
3. 명령어가 완료될 때까지 기다린 후, 로컬 모델이 반환한 텍스트 출력(STDOUT)을 읽다.
4. 그 결과물을 당신의 컨텍스트에 포함시켜 사용자에게 요약/보고해 줍니다.

## 주의 사항
- `ollama run` 명령어 실행 시, 프롬프트 문자열 내의 큰따옴표(`"`)나 특수문자가 Bash 쉘에서 구문 오류를 일으키지 않도록 적절히 이스케이프 처리해야 한다. 가급적 프롬프트를 임시 파일(예: `/tmp/prompt.txt`)에 저장한 뒤, `cat /tmp/prompt.txt | ollama run qwen2.5-coder:7b` 형태로 파이프라인을 구성하는 것이 가장 안전한다.
- 시간이 다소 걸릴 수 있으므로(CPU 연산), 백그라운드로 실행 후 상태를 모니터링해라.
