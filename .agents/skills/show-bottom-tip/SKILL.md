# 하단 팁 표시 스킬

이 스킬은 애플리케이션 내의 페이지, 모달 또는 목록 하단에 일관되고 미려한 방식으로 단축키 안내 및 사용자 팁을 제공하는 표준 UI 패턴을 준수하도록 강제한다.

## 1. 사용 시기

다음 상황에서 이 스킬을 호출하여 UI를 작성하십시오:
- 사용자가 UI 컴포넌트에 "팁", "안내문구", "하단 가이드" 등을 추가해달라고 요청할 때
- 화살표 키, 스페이스바, 엔터 키 등을 활용하는 복잡한 키보드 단축키를 구현하여 사용자에게 키 조작법을 알려주어야 할 때

## 2. 디자인 기준 (하단 팁 패턴)

일관된 사용자 경험을 위해 모든 팁은 표준화된 스타일로 렌더링되어야 한다.

### 시각적 스타일
- **위치:** 관련 컨테이너(모달, 페이지 섹션, 리스트)의 가장 아래쪽에 배치한다.
- **포맷:** 항상 전구 이모지 `💡 팁:` 또는 `💡 단축키 팁:`으로 시작한다.
- **타이포그래피:**
  - 너무 튀지 않도록 `text-xs` (또는 화면 상황에 따라 `text-sm`) 크기와 차분한 회색 톤(`text-muted-foreground` 등)을 사용한다.
  - 중요 키 조작법이나 핵심 액션 단어는 `<strong>` 또는 `font-semibold` 스타일을 적용해 강조한다.
- **컨테이너 (선택사항):** 약간의 가독성 향상이 필요한 경우, 은은한 배경색과 테두리가 들어간 상자 안에 배치한다.

### 표준 코드 블록 예시
```tsx
<div className="mt-4 p-3 bg-secondary/20 rounded-md border border-border/40">
  <p className="text-xs text-muted-foreground">
    💡 <strong>단축키 팁:</strong> <strong>방향키(↑, ↓)</strong>로 이동한 뒤 <strong>스페이스(Space)</strong>를 눌러 항목을 선택할 수 있다.
  </p>
</div>
```
*(공간이 협소한 모달 등의 레이아웃에서는 배경 상자 없이 심플하게 `<p className="text-xs text-muted-foreground">` 태그만 하단에 배치하는 것도 허용됩니다.)*

## 3. 실행 단계

1. 대상 UI 컴포넌트의 최하단에서 팁을 추가하기에 가장 적절한 위치를 결정한다.
2. 전달하고자 하는 팁 내용을 명확하고 간결하게 한국어로 작성한다.
3. 표준 시각 클래스(Tailwind CSS)를 부여한다.
4. 중요 단축키(예: ↑, ↓, Space, Esc, Enter, Alt 등)를 나타내는 텍스트는 굵게 처리하여 가시성을 높이다.

## ⛔ 독단적 결정 금지 (Do NOT Decide Alone)

- 전반적인 레이아웃에 큰 영향을 주는 전역 팁 배치 위치나 고정 방식을 사용자의 동의 없이 임의로 변경하는 행위 금지
- 기존에 렌더링되어 있는 팁/안내 문구를 불필요하다고 판단하여 사용자 확인 없이 임의로 삭제하는 행위 금지
