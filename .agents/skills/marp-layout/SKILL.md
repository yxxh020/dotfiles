# Marp 슬라이드 레이아웃 최적화 스킬

Marp로 마크다운 슬라이드를 작성할 때, 다단 표 구조의 한계로 텍스트가 글자 단위로 잘리거나 레이아웃이 깨지는 현상을 방지한다.

## 문제 상황

1. 슬라이드(16:9 비율)는 가로 너비가 고정되어 있으므로, 5개 이상의 열을 가진 `<table>`을 사용하면 각 열의 공간이 지나치게 협소해진다.
2. 좁은 너비 안에서 한글 텍스트가 들어가면 글자 단위로 지저분하게 쪼개지는 현상(예: `모\n르는`)이 발생하여 가독성을 심각하게 해친다.

## 해결 규칙

### 1. Flexbox 카드 레이아웃 (가장 권장)
세로 열 표 대신, 가로로 나열되는 독립적인 카드 형태의 Flexbox 구조를 사용한다.
- **단어 잘림 방지 (필수)**: 컨테이너와 `.card` 클래스에 `word-break: keep-all;` 속성을 반드시 부여하여 한글 단어가 중간에 찢어지지 않게 한다.
- **임의 줄바꿈 금지**: 셀이나 카드 안에서는 특별한 이유가 없는 한 `<br>` 태그로 인위적으로 줄바꿈하지 않는다. `word-break: keep-all;`에 의해 단어 단위로 자연스럽게 래핑되도록 맡긴다.
- **구분선 및 시각화**: 카드의 제목과 본문 사이에 얇은 구분선을 삽입하고, 직관적인 이모지를 적극 활용한다.
- **시선 통제**: 특정 카드를 강조할 때, 강조 카드는 진하게 처리하고 나머지는 `opacity: 0.5;`로 흐리게 만들어 시선을 유도한다.

### 2. 가로 행 테이블 기반
텍스트 분량이 많아 반드시 표를 써야 한다면, 열 단위가 아닌 행 단위로 나열하는 세로로 긴 표를 작성하여 가로 공간을 충분히 확보한다.

### 3. 도형 중심 및 텍스트 최소화
텍스트를 최소화할 수 있다면, CSS로 원형 등의 도형을 디자인하고 텍스트 대신 화살표(`➡`) 등으로 흐름만 시각화한다.
