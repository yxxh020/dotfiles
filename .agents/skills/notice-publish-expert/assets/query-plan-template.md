# 공지 쿼리 준비

상태: 설계 초안 / 실행 불가

공지 DB 스키마가 미확정일 때 사용하는 문서입니다. 이 문서의 초안을 실행 파일로 취급하지 않습니다. 실제 테이블과 제약이 확인되면 적용·검증·복구 SQL을 별도 파일로 작성합니다.

## 확인할 계약

| 항목 | 확인 결과 |
|---|---|
| 실제 테이블·열·자료형 | 미확정 |
| 공지 키 고유 제약 | 미확정 |
| 원문·리비전 저장 방식 | 미확정 |
| 대상·고정·공개 상태 저장 방식 | 미확정 |
| 게시일·조회수 보존 방식 | 미확정 |
| 관리자·수신 대상 조회 경로 | 미구현 여부 확인 필요 |

## 적용 쿼리 설계

대상 공지 키와 리비전을 명시하고, 기존 값 또는 리비전의 일치를 검사합니다. 동일 리비전 재실행은 중복 등록하거나 게시일·조회수를 초기화하지 않아야 합니다. 다른 공지의 삭제나 고정 해제는 포함하지 않습니다.

## 검증 쿼리 설계

공지 키로 대상 행 수와 원문·리비전·대상·고정·공개 상태를 확인합니다. 문서 원문과 SQL의 본문 일치를 검사합니다.

## 복구 쿼리 설계

신규 등록과 기존 공지 수정을 구분합니다. 수정은 적용 전 값을 복원하고, 복구 대상이 이번 적용 리비전과 일치하는지 검사하여 다른 운영 변경을 덮어쓰지 않습니다.

## 실행 파일 준비 조건

테이블과 고유 제약, 실제 조회 경로, 원문 인코딩, 재시도 동작 및 복구 조건이 확인되면 `apply.sql`, `verify.sql`, `rollback.sql`을 작성합니다. 완료되지 않은 항목을 명시하고 그 전에는 `ready`로 표시하지 않습니다.
