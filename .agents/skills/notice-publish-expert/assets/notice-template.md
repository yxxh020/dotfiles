# 공지 제목

사용자에게 보일 공지 본문을 작성합니다. 서비스에 게시할 범위는 제목과 본문이며, 위 메타데이터와 배포 이력은 제외합니다.

사용자가 체감하는 변화, 필요한 행동, 적용 일시를 명확하게 안내합니다. 아직 운영에 반영되지 않은 기능은 이미 제공된다고 표현하지 않습니다. 등록일과 게시 예정일은 구분합니다.
