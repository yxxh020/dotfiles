> **[안내]** 이 파일은 각 프로젝트가 복사해갈 때 프로젝트 상황에 맞게 수정하여 사용하는 스킬 템플릿이다.
> 색상값(`bg-[#xxxxxx]`)은 프로젝트의 브랜드 컬러로 교체한다. 적용 후 이 안내 문구를 제거한다.

# 카테고리 블록 헤더 스킬

목록 화면 또는 상세 화면에서 자료 분류(카테고리) 그룹 타이틀을 표시할 때, 단순 텍스트가 아닌 **색상 배경 블록**과 **하단 경계선**이 반드시 쌍으로 결합된 레이아웃을 강제하는 UI 규칙이다.

## UI 가이드라인 표준 규칙

각 리소스 그룹을 표시하는 분류 타이틀은 다음과 같이 **브랜드 컬러 배경 블록 스타일**과 **하단 경계선**이 쌍으로 결합된 레이아웃을 사용해야 한다.

### 1. 적용 예시 (TSX 코드)

```tsx
<div className="flex flex-col mt-8 sm:mt-10 px-3 sm:px-4">
  {/* 카테고리/분류명 박스 */}
  <div className="w-fit">
    <div className="bg-<brand-color> dark:bg-<brand-color-dark> text-white font-semibold text-sm sm:text-base px-6 py-2">
      {typeName}
    </div>
  </div>
  {/* 하단 경계선 (전체 너비, 동일 브랜드 컬러) */}
  <div className="h-[2px] bg-<brand-color> dark:bg-<brand-color-dark> w-full" />
</div>
```

### 2. 핵심 준수 요건

| 요건 | 규칙 |
|------|------|
| **배경 색상** | 브랜드 컬러를 사용한다 (다크모드용 대체 컬러 별도 지정). |
| **너비 제한** | 텍스트 상자는 `w-fit` 처리로 분류명 텍스트 길이에 딱 맞게 래핑한다. |
| **하단 경계선** | 텍스트 상자 바로 아래에 전체 너비(`w-full`)의 `h-[2px]` 두께를 가진 동일 색상 실선을 배치한다. |
| **쌍 원칙** | 배경 박스와 하단 경계선은 항상 함께 사용한다. 하나만 단독으로 사용하지 않는다. |
| **일관성** | 동일 도메인의 목록 화면과 상세 화면 모두에서 완벽히 일치해야 한다. |

### 3. 프로젝트별 색상 적용 예시

```tsx
{/* 녹색 브랜드 예시 */}
<div className="bg-[#369539] dark:bg-green-700 text-white font-semibold text-sm sm:text-base px-6 py-2">
  {typeName}
</div>
<div className="h-[2px] bg-[#369539] dark:bg-green-700 w-full" />
```

## 적용 체크리스트

- [ ] 카테고리 제목이 단순 텍스트가 아닌 배경 색상 블록으로 감싸져 있는가?
- [ ] 하단에 동일 브랜드 컬러의 `h-[2px]` 전체 너비 경계선이 있는가?
- [ ] `w-fit`으로 텍스트 길이에 맞게 박스가 조절되는가?
- [ ] 다크모드에서 대체 컬러가 올바르게 적용되는가?
- [ ] 같은 도메인의 다른 화면에서도 동일한 스타일이 사용되는가?
