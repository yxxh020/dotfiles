# `ai-grader` 스킬 지침서

이 스킬은 채점 기준표(Rubric)에 기반하여 제출물(과제, 에세이, 코드 등)을 평가하고, 공정하고 편향 없는 채점 결과와 단계별 피드백을 생성하는 역할을 한다.

단건 상세 피드백(Chain-of-Thought)과 대량 일괄 채점(Batch Grading) 두 가지 모드를 모두 지원한다.

## 언제 이 스킬을 호출하는가?

- 이미 정의된 루브릭(Rubric)을 기준으로 제출물을 평가해야 할 때 (루브릭이 아직 없다면 `rubric-generator` 스킬로 먼저 생성 권장)
- 왜 이런 점수가 나왔는지 구체적인 이유(Chain-of-Thought)를 설명할 피드백이 필요할 때
- 여러 명의 제출물을 한 번에 순회하며 일괄 평가를 진행해야 할 때
- 설정 파일(예: `grading_config.json`)에 정의된 복합적인 채점 파이프라인을 가동해야 할 때

## 작동 방식 및 행동 규칙

### 모드 1: 단건 상세 평가 (Chain-of-Thought)

1. **입력 데이터 확보**:
   - 채점 기준표(Rubric) 파일 경로
   - 채점할 제출물(텍스트, 코드, 파일 등)

2. **Chain-of-Thought 평가 수행**:
   - 곧바로 점수를 내지 않는다.
   - 루브릭의 각 항목(Criteria)별로 제출물이 어느 수준에 해당하는지 **분석 이유를 먼저 서술(추론)**한다.
   - 분석 결과에 기반하여 각 항목별 점수를 산정하고 총점을 합산한다.

3. **결과 출력 포맷**:
   ```markdown
   ## 채점 결과 보고서

   - **총점**: [산출된 총점] / [만점]

   ### 항목별 평가 세부사항
   1. [항목 1 이름]: [획득 점수] / [배점]
      - **평가 이유**: (CoT 추론 과정과 피드백 기록)
   2. [항목 2 이름]: [획득 점수] / [배점]
      - **평가 이유**: (CoT 추론 과정과 피드백 기록)

   ### 종합 피드백 및 개선점
   (제출자에게 전달할 구체적인 조언)
   ```

### 모드 2: 대량 일괄 채점 (Batch Grading)

1. **환경 및 설정(Config) 분석**:
   - 작업 디렉터리 내의 채점 설정 파일(예: `config.yaml`, `config.json`)을 우선적으로 읽어온다.
   - 지시사항, 페널티 규칙(지각, 포맷 위반 등), 기본 점수 등을 파악한다.

2. **일괄 평가 수행**:
   - 지정된 폴더 안의 모든 제출물을 순회한다.
   - 각 제출물에 대해 설정된 루브릭을 적용하여 점수를 도출한다.
   - 코드를 평가할 경우, 실행 오류 등을 파악하여 사전에 정의된 페널티 규정을 엄격하게 적용한다.

3. **결과 리포팅**:
   - **전체 채점 결과가 요약된 표(또는 CSV 형태의 데이터)**를 출력한다.
   - 전체 평균 점수, 가장 많이 틀린 항목이나 취약점 등 종합 분석 리포트를 함께 제시한다.

   ```markdown
   ## 전체 일괄 채점 결과 요약

   | 제출자 | 제출 파일 | 획득 점수 | 비고 (페널티 등) |
   | :--- | :--- | :---: | :--- |
   | 홍길동 | `hw_hong.md` | 95 | 포맷 우수 |
   | 김철수 | `hw_kim.md`  | 80 | -5 (지각 제출) |
   ```
