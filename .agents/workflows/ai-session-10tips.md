# /ai-session-10tips 워크플로우

AI 코딩 에이전트(Antigravity 등)와 함께 복잡하고 도전적인 작업을 시작할 때 참고하고 실행하는 워크플로우이다. 이 워크플로우는 [Boris Cherny의 10가지 팁](https://youtu.be/2WJzwwvzbBQ)을 Antigravity 환경에 맞게 이식한 것이다.

**[에이전트 행동 지침]** 이 명령어가 호출되면, 에이전트는 아래 10가지 철학을 숙지한 상태에서 현재 작업의 '계획수립(2번)', '서브에이전트 활용 여부(8번)', '검증 루프 구축(9번)'에 대한 전략을 즉시 요약하여 브리핑해야 한다.

1. **병렬 세션 활용 (Parallelization)**: 터미널 탭별로 별개의 대화 세션(Conversation)을 분리하여 각개 격파한다. 하나의 복잡한 창에 모든 것을 우겨넣지 마세요.
2. **계획부터 시작 (Plan 모드)**: 코드를 당장 수정하기 전에 반드시 명확한 계획부터 세웁니다 (Plan-First).
3. **시스템 룰 지속 업데이트**: 에이전트가 실수를 반복하면, "이 실수를 user_rules나 프로젝트 규칙에 기록해 둬"라고 즉각 지시하여 구조적으로 방어한다.
4. **커스텀 스킬 적극 등록**: 나만의 반복 작업(로그확인, 특정 린터)은 언제든 `/ai-add-skill`을 통해 `.agents/skills/`에 등록하여 무기로 만듭니다.
5. **버그 해결의 위임 (Let AI fix)**: 자잘한 지시를 내리지 않고, CI 에러나 실패 로그를 통째로 던진 뒤 "fix(고쳐)" 로 전권 위임한다.
6. **도전적인 프롬프팅 (Provocative Prompting)**: 만족스럽지 않을 때, "내 코드를 신랄하게 비판해(Grill me)", "더 우아하고 참신한 방법으로 다시 짜봐" 라고 에이전트의 한계를 푸시한다.
7. **컨텍스트 최적화 (Environment Optimization)**: 대화가 낡고 무거워지면 새 세션을 열고 이전 세션 정보를 요약(KI)하여 환승한다.
8. **서브 에이전트 활용 (Use Subagents)**: 브라우저 조작이나 단순 데이터 긁기와 같은 독립 작업은 `browser_subagent` 등 서브 에이전트에게 맡겨 메인 맥락을 보호한다.
9. **스스로 검증하는 루프 (Verification Loop)**: 에이전트가 코드를 짠 후 테스트 코드, 터미널 실행, curl 테스트 등을 이용해 스스로 작동 여부를 입증하게 만듭니다.
10. **시각적/설명적 학습 모드**: 에이전트가 짠 코드를 이해하기 어렵다면 "ASCII 다이어그램으로 설계도를 그려서 설명해라" 라며 지식 흡수 도구로 전환한다.
