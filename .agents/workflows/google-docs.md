# 브라우저 기반 구글 문서 열람 워크플로우
복잡한 API 연동 없이 로컬 크롬의 로그인 세션을 재활용하여 문서를 확인한다.

1. `browser_subagent` 도구를 호출해라.
2. 사용자가 제공한 구글 문서 URL(Docs, Sheets 등)에 접속하도록 지시해라.
3. 문서 화면에서 주요 텍스트 내용들을 읽어들이고, 필요하다면 전체 구조를 파악하기 위해 화면을 스크롤해라.
4. 수집한 정보의 핵심 내용을 3줄 요약하여 사용자에게 보고해라.
5. 사용자가 요구한 작업을 해라
