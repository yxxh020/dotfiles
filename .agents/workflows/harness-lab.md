# 하네스 랩 워크플로우

사용자가 요청한 작업(예: 여행 계획, 일상 업무, 개발 프로젝트)에 맞는 하네스 블루프린트를 설계하고 생성한다.

> 하네스 설계 규칙과 구조는 [harness-lab 스킬](../skills/harness-lab/SKILL.md)을 참조한다.

## 실행 절차

1. `harness-lab` 스킬 문서를 읽고 지침을 이해한다
2. 사용자의 요청에 맞추어 하네스 블루프린트 생성을 시작한다
3. 스킬 문서에 정의된 Phase를 순서대로 진행한다
4. 각 Phase 완료 후 사용자 피드백을 수집한다
