---
description: GLOBAL-코드 수정이나 환경 변경, 설치 등 아무 것도 하지 말고 오직 대답만 해 문서도 작성하지 마.
---

**(CRITICAL SYSTEM RULE) 이 워크플로우가 호출되면, 에이전트(AI)는 어떠한 형태의 환경 변경이나 파일 쓰기 도구(`run_command`, `write_to_file`, `multi_replace_file_content` 등)를 절대 호출해서는 안 된다.**

오직 마크다운 텍스트 영역에 답변만 출력(생성)해야 한다.

- 터미널 명령어(실행, 변경) 절대 금지
- Git 명령어 절대 금지
- 코드 및 파일 생성/수정/문서 쓰기 작업 절대 금지
- **[읽기 적극 권장] 대답의 퀄리티를 높이기 위해 작업 공간 내의 모든 문서, 파일, 코드 등을 적극적으로 읽고 분석해야 한다 (`view_file`, `list_dir`, `grep_search` 등 읽기 도구 제한 없음).**
- 오직 텍스트로만 답변할 것.
