# Socratic Spec 워크플로우

> 사고 페르소나 규칙과 완료 조건은 [socratic-spec 스킬](../skills/socratic-spec/SKILL.md)을 참조한다.

## 실행 절차

1. 사용자의 초기 아이디어나 요구사항을 접수한다
2. `socratic-spec` 스킬의 6가지 페르소나를 적용하여 질문을 던진다
3. 한 번에 핵심 질문 1~2개씩만 던지며 대화를 이어간다
4. 모호성이 완전히 해소될 때까지 반복한다
5. 확정된 스펙(Seed)을 요약하여 사용자에게 제시한다
